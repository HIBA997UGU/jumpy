# Jumpy Game

## About
Jumpy is a Python game project developed to practice game programming, game logic, and resource management.

## Technologies
- Python
- Pygame (if used by the project)

## Project Structure
- `jumpy-tab.py` — main game file
- `enemy.py` — enemy-related logic
- `spritesheet.py` — sprite handling
- `assets/` — game resources

## How to Run

1. Install Python.
2. Install the required dependencies.
3. Run the main Python file:

```bash
python jumpy-tab.py
```

## Features
- Game mechanics and player interactions
- Enemy logic
- Sprite-based graphics
